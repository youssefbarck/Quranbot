# بوت الحصون الخمسة — الإصدار 4.1.0 (ملف واحد)

> مرافقك الشخصي لحفظ القرآن الكريم وفق منهج الحصون الخمسة.

## ✨ المميزات

- **ملف واحد شامل** — كل المنطق في `bot.py` واحد (بدون تعقيد ملفات متعددة)
- **5 حصون متكاملة** — تهيئة، تحضير، حفظ، مراجعة قريب، مراجعة بعيد
- **لوحة تحكم شاملة** — كل الأساسيات في شاشة واحدة منظّمة
- **8 تذكيرات يومية** — قابلة للتخصيص لكل مستخدم
- **أوامر طبيعية** — «وش نحفظ اليوم؟» «حفظت الوجه 41» «قريت الورد»
- **قاعدة بيانات دائمة** — PostgreSQL على Render، أو SQLite محليًا
- **Keep-alive** — يبقي البوت مستيقظًا على Render

## 📁 الملفات

```
bot.py           — كل المنطق (4500+ سطر، 28 قسمًا)
render.yaml      — إعداد Render.com
requirements.txt — المكتبات المطلوبة
runtime.txt      — إصدار Python (3.11.9)
.env.example     — نموذج لمتغيرات البيئة
.gitignore       — ملفات يُستثنى رفعها
```

## 🚀 النشر على Render.com

1. ارفع هذه الملفات إلى مستودع GitHub
2. على Render → New → Web Service → اربط المستودع
3. تأكد من الإعدادات:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python -u bot.py`
4. أضف متغيرات البيئة:
   - `TELEGRAM_BOT_TOKEN` — توكن البوت من BotFather
   - `DATABASE_URL` — رابط PostgreSQL من Render
   - `ADMIN_TELEGRAM_ID` — معرّفك في تيليجرام (اختياري)
5. Deploy!

## 🏃‍♀️ التشغيل المحلي

```bash
# 1. تثبيت المكتبات
pip install -r requirements.txt

# 2. ضبط متغيرات البيئة
export TELEGRAM_BOT_TOKEN=your_token_here
export DATABASE_URL=file:./quranbot.db  # SQLite محلي

# 3. التشغيل
python bot.py
```
