# 📖 بوت الحصون الخمسة لحفظ القرآن الكريم

> بوت تلغرام ذكي يحفظ تقدمك في حفظ القرآن بنظام "الحصون الخمسة" المتكامل: حفظ يومي، مراجعة يومية، حفظ أسبوعي، مراجعة أسبوعية (5 مواعيد)، ومراجعة شهرية.

## 🏰 الحصون الخمسة

| # | الحصن | المعنى | التكرار |
|---|------|--------|---------|
| 1️⃣ | **الحفظ اليومي** | حفظ صفحة جديدة كل يوم | يومياً |
| 2️⃣ | **المراجعة اليومية** | مراجعة ما حُفظ اليوم | يومياً (مساءً) |
| 3️⃣ | **الحفظ الأسبوعي** | مراجعة آخر 7 أيام من الحفظ | يومياً |
| 4️⃣ | **المراجعة الأسبوعية** | 5 مرات للصفحة الواحدة: ليلة، ليل، ثلث، اربعاء، خميس | موزعة على 5 أيام |
| 5️⃣ | **المراجعة الشهرية** | مراجعة كل صفحات الشهر | نهاية كل شهر |

## ⏰ التذكيرات اليومية

| الوقت | التذكير |
|-------|---------|
| 🌅 **08:00 صباحاً** | قراءة حزبين (20 صفحة) |
| ☀️ **13:00 ظهراً** | الاستماع لحزب (10 صفحات) |
| 🌙 **20:00 مساءً** | سؤال تفاعلي: "هل أنهيتِ الحفظ اليوم؟" |

> يمكن تغيير كل الأوقات لاحقاً عبر أمر `/settime`

## ✨ كيف يعمل البوت؟

### 1️⃣ التهيئة التفاعلية
عند إرسال `/start`، البوت يسألك: "ماذا حفظت؟"
أجبي بأحد الخيارات:
- `صفحة 50` — حفظت إلى صفحة 50
- `جزء 3` — حفظت 3 أجزاء كاملة
- `سورة الكهف` — حفظت حتى سورة الكهف
- `ختمت القرآن` — حفظت كل القرآن
- `0` — تبدأ من الصفحة الأولى

### 2️⃣ البوت يحسب نقطة البداية
يحسب تلقائياً الصفحة التالية للحفظ، وينشئ لك سجل مراجعة أسبوعية لكل صفحة.

### 3️⃣ التذكيرات اليومية
البوت يرسل 3 رسائل يومياً حسب توقيتك المحلي.

## 🏗️ التقنيات المستخدمة

- **Python 3.11** + **python-telegram-bot v21** (async)
- **SQLAlchemy 2.0 + asyncpg** للتعامل مع قاعدة البيانات
- **Neon Tech (Postgres)** قاعدة بيانات سحابية مجانية
- **APScheduler** لجدولة التذكيرات
- **Render (Web Service - Free)** للاستضافة مع **keep-alive مدمج** (لا حاجة لمنصة خارجية)
- **GitHub** للمستودع البرمجي

## 🚀 خطوات النشر الكاملة

### 1️⃣ إنشاء بوت تلغرام

1. ابحث عن [@BotFather](https://t.me/BotFather) في تلغرام
2. أرسل `/newbot` واتبع التعليمات
3. احفظ **التوكن** (مثال: `123456789:ABCdefGhI...`)
4. للحصول على معرفك: راسل [@userinfobot](https://t.me/userinfobot)

### 2️⃣ إنشاء قاعدة بيانات Neon

1. اذهب إلى [neon.tech](https://neon.tech) وسجّل مجاناً
2. أنشئ مشروعاً جديداً
3. انسخ **Connection String**
4. تأكد من وجود `?sslmode=require` في الرابط

### 3️⃣ رفع الكود إلى GitHub

```bash
git init
git add .
git commit -m "بوت الحصون الخمسة لحفظ القرآن"
git branch -M main
git remote add origin https://github.com/USERNAME/quran-husun-bot.git
git push -u origin main
```

### 4️⃣ النشر على Render (Web Service مجاني)

> ⚠️ **مهم**: اختر **Web Service** (وليس Background Worker — لأن Worker ليس مجانياً على Render).
> البوت يستخدم **keep-alive مدمج** (خادم HTTP + self-ping كل 280 ثانية) ليبقى مستيقظاً 24/7 على الخطة المجانية دون الحاجة لـ UptimeRobot أو أي منصة خارجية.

1. اذهب إلى [render.com](https://render.com) وسجّل
2. اختر **New + → Web Service**
3. اربط GitHub واختر المستودع
4. اترك الإعدادات الافتراضية:
   - Type: **Web Service**
   - Environment: **Python 3**
   - Plan: **Free**
   - Build: `pip install -r requirements.txt`
   - Start: `python -m bot.main`
   - Health Check Path: `/health`
5. أضف متغيرات البيئة:

| المتغير | القيمة |
|---------|--------|
| `TELEGRAM_BOT_TOKEN` | التوكن من BotFather |
| `DATABASE_URL` | رابط Neon (postgresql://...) |
| `ADMIN_TELEGRAM_ID` | معرفك في تلغرام |
| `MORNING_TIME` | `08:00` |
| `MIDDAY_TIME` | `13:00` |
| `EVENING_TIME` | `20:00` |
| `DEFAULT_TIMEZONE` | `Africa/Algiers` |
| `KEEPALIVE_ENABLED` | `true` |
| `KEEPALIVE_INTERVAL` | `280` |

> 📌 **ملاحظة**: Render يضيف متغير `RENDER_EXTERNAL_URL` تلقائياً — لا تضبطه يدوياً.

6. اضغط **Create Web Service** وانتظر دقيقتين حتى يكتمل البناء والإطلاق
7. في قسم **Logs** يجب أن ترى: `keep-alive نشط — self-ping كل 280 ثانية`

### 5️⃣ تفعيل البوت

1. ابحث عن البوت في تلغرام
2. أرسل `/start`
3. أجب على السؤال: "ماذا حفظت؟"
4. استخدم `/today` لمهام اليوم
