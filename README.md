# 🕌 بوت الحصون الخمسة لحفظ القرآن الكريم

نظام شخصي ذكي لإدارة رحلة الحفظ وفق منهج **الحصون الخمسة**، يعمل كـ "مدير شخصي للحفظ".

## ✨ المميزات

### 🏰 الحصون الخمسة

1. **الحصن الأول — التهيئة**
   - 📖 ختمة قراءة كل 30 يومًا (حزبان/يوم)
   - 🎧 ختمة استماع كل 60 يومًا (حزب/يوم، مستقلة عن القراءة)

2. **الحصن الثاني — التحضير**
   - 📚 التحضير الأسبوعي (نطاق ديناميكي حسب المقدار)
   - 🌙 التحضير الليلي (وجه الغد)
   - ⏱️ التحضير القبلي (مؤقّت 15 دقيقة)

3. **الحصن الثالث — الحفظ الجديد**
   - الوجه القادم بناءً على `last_hifz_page`
   - لا يتقدّم تلقائيًا إذا فات يوم — يجب التأكيد

4. **الحصن الرابع — مراجعة القريب**
   - نافذة متحركة آخر 20 وجهًا محفوظة

5. **الحصن الخامس — مراجعة البعيد**
   - 40 وجهًا لكل دورة، مستقلة عن الحفظ
   - دورات دائرية (1 → 2 → ... → N → 1)

### 🎯 المبادئ الأساسية

- ✅ **State-Based**: المحرك يقرأ حالة المستخدم ويحسب الخطة
- ✅ **Dynamic**: كل المهام محسوبة من الحالة الحالية
- ✅ **Multi-user**: كل مستخدم له بياناته المنفصلة
- ✅ **Persistent**: PostgreSQL/SQLite — لا تُفقد البيانات
- ✅ **Toggleable**: أزرار التسجيل يمكن التراجع عنها
- ✅ **Smart Suggestions**: تحليل سلوك المستخدم (لا تغيير تلقائي)
- ✅ **8 تذكيرات يومية قابلة للتخصيص**
- ✅ **NLP بسيط** لفهم أوامر عربية طبيعية

## 🚀 التشغيل المحلي

```bash
# 1. تثبيت المتطلبات
pip install -r requirements.txt

# 2. إعداد البيئة
cp .env.example .env
# عدّل القيم في .env

# 3. تشغيل البوت
python -m bot.main
```

## 🧪 الاختبارات

```bash
python tests/test_engines.py
# أو
python -m pytest tests/test_engines.py -v
```

الاختبارات تغطّي 18+ سيناريو من مواصفات المستخدم:
- مستخدم يبدأ من الوجه 1 / 40 / 120
- حفظ وجه / وجهين يوميًا
- تخطي يوم (لا يتحرك الحفظ)
- تغيير المقدار اليومي
- مراجعة القريب (20 وجه متحركة)
- مراجعة البعيد (40 وجه/دورة)
- انتقال الدورات
- إعادة دورة القراءة بعد الحزب 60
- إعادة دورة الاستماع بعد الحزب 60
- الوصول إلى نهاية القرآن
- تعدد المستخدمين (عزل البيانات)
- استمرارية البيانات عبر الجلسات

## 🌐 النشر على Render

1. اربط المستودع بـ Render
2. أضف متغيرات البيئة (TELEGRAM_BOT_TOKEN, DATABASE_URL, ...)
3. ابدأ النشر — `render.yaml` مُعد مسبقًا

## 💬 الأوامر الطبيعية المدعومة

- «وش نحفظ اليوم؟» → ورد اليوم
- «وين وصلت؟» → التقدم
- «حفظت الوجه 41» → تسجيل الحفظ
- «قريت الورد» → تأكيد القراءة
- «اليوم ما قدرت» → تسجيل كغير مكتمل
- «أريد نغيّر الحفظ إلى 2» → تعديل المقدار
